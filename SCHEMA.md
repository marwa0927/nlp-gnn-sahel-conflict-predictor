## Columns

### Index / key columns

| Column | dtype | Description |
|--------|-------|-------------|
| `node_id` | `object` (str) | City node identifier (e.g. `"gao"`, `"niamey"`) — matches `NODES_DICT` keys in `data/nodes.py` |
| `date` | `datetime64[ns]` | Calendar date at daily granularity |

### Base features

| Column | dtype | Description |
|--------|-------|-------------|
| `avg_tone` | `float64` | Mean GDELT AvgTone across all events assigned to the node on that date. Higher = more positive media framing. |
| `goldstein` | `float64` | Mean GDELT GoldsteinScale (−10 to +10). Negative = destabilising events. |
| `n_articles` | `Int64` (nullable) | Total number of source articles (NumArticles) — proxy for event salience. |
| `conflict_events` | `Int64` (nullable) | Count of events with CAMEO root code 18–20 (assault, fight, use of unconventional mass violence). |
| `unrest_events` | `Int64` (nullable) | Count of events with CAMEO root code 14–17 (protest, demand, disapprove, reject). |
| `n_actors` | `float64` | Number of distinct Actor1Name values — proxy for actor diversity. |

### Lag / rolling features (generated by `add_lag_features`)

For each base feature `{col}` the following three derived columns are appended:

| Column pattern | dtype | Description |
|----------------|-------|-------------|
| `{col}_lag7` | `float64` / `Int64` | Value of `{col}` 7 days prior for the same node. |
| `{col}_roll7` | `float64` | 7-day trailing rolling mean of `{col}` for the same node. |
| `{col}_roll14` | `float64` | 14-day trailing rolling mean of `{col}` for the same node. |

Full list of lag/roll columns (18 total):

```
avg_tone_lag7,         avg_tone_roll7,         avg_tone_roll14
goldstein_lag7,        goldstein_roll7,         goldstein_roll14
n_articles_lag7,       n_articles_roll7,        n_articles_roll14
conflict_events_lag7,  conflict_events_roll7,   conflict_events_roll14
unrest_events_lag7,    unrest_events_roll7,     unrest_events_roll14
n_actors_lag7,         n_actors_roll7,          n_actors_roll14
```

## Missing-value convention

All (node, date) pairs exist in the parquet file. Days with no GDELT events
assigned to a node have all base features set to **0.0**. Lag/roll features
at the start of each node's time series (where the rolling window extends
before 2020-01-01) are also filled with **0.0**.

**Person B must NOT** treat 0.0 as NaN when building graph edge weights or
GNN input tensors.

## Known issues & Person B action items

| Issue | Detail | Action required by Person B |
|-------|--------|------------------------------|
| Extra `index` column | A leftover integer index column is present (27 cols, not 26). | Drop on load: `df.drop(columns=["index"], errors="ignore")` |
| Mixed dtypes | `n_articles`, `conflict_events`, `unrest_events` are `Int64` (nullable pandas type), not `float64`. PyTorch does not accept nullable Int64. | Cast on load: `df[col] = df[col].astype("float32")` for all feature columns before tensor conversion. |

### Recommended load snippet for Person B

```python
import pandas as pd

df = pd.read_parquet("data/processed/features_daily.parquet")
df = df.drop(columns=["index"], errors="ignore")

feature_cols = [c for c in df.columns if c not in ["node_id", "date"]]
df[feature_cols] = df[feature_cols].astype("float32")
```

> **Source:** ACLED export (`data/raw/acled_sahel_raw.csv`) — Mali, Niger, Burkina Faso, Chad, Mauritania, 2018–2024, all event types

### File properties

| Property | Value |
|----------|-------|
| Path | `data/processed/labels_daily.parquet` |
| Format | Apache Parquet (PyArrow engine) |
| Expected shape | `(25 nodes × 2,557 days) = 63,925 rows × 4 columns` |
| Date range | 2018-01-01 → 2024-12-31 (inclusive) |
| Missing days | Reindexed to full grid, filled with **0** |

### Columns

| Column | dtype | Description |
|--------|-------|-------------|
| `node_id` | `object` (str) | City node identifier — same 25 nodes as features |
| `date` | `datetime64[ns]` | Calendar date |
| `y_conflict` | `int8` | 1 if any Battles / Explosions-Remote violence / Violence against civilians event was recorded within 80 km of the node on that day; else 0 |
| `y_unrest` | `int8` | 1 if any Protests / Riots / Strategic developments event was recorded within 80 km of the node on that day; else 0 |
| `fatalities` | `int32` | Sum of ACLED fatalities for all events assigned to the node on that day |

### Event-type mapping

```
CONFLICT_TYPES = ["Battles", "Explosions/Remote violence", "Violence against civilians"]
UNREST_TYPES   = ["Protests", "Riots", "Strategic developments"]
```

### Class balance

Conflict and unrest rates are highly imbalanced — the majority of node-days have no event.
Run `python data/validate_labels.py` for exact per-country breakdown.

| Target | Approx. % days = 1 |
|--------|---------------------|
| `y_conflict` | ~5–15% (higher in Chad, Burkina Faso) |
| `y_unrest` | ~2–8% (higher in Niger, Mali) |

## Train / Val Splits Contract

> **Defined in:** `evaluation/splits.py`  
> **Person B MUST use these exact splits — no custom splitting allowed.**

Walk-forward cross-validation with three expanding-window splits:

| Split | Train range | Val range |
|-------|-------------|-----------|
| 1 | 2020-01-01 → 2021-12-31 | 2022-01-01 → 2022-12-31 |
| 2 | 2020-01-01 → 2022-12-31 | 2023-01-01 → 2023-12-31 |
| 3 | 2020-01-01 → 2023-12-31 | 2024-01-01 → 2024-12-31 |

Use `evaluation/splits.get_split_data(df, split)` to obtain `(df_train, df_val)`.  
Use `evaluation/splits.get_node_order()` to get the canonical 25-node list for aligning
X matrix rows with adjacency matrix rows.
